# Independent expectations for feature 03

Prepared before reading a candidate implementation or Builder explanation. Only specification/design documents and pinned Regional BFT authority were used. Source baseline is `ada48a584ad4de15e302c479ee8cd41b9e2a8d9b`; Regional BFT pin was read-only verified as `691cfc14daaa53c1a08cbd87dd3fe0cd60a214e6`. Commonware is pinned to 2026.10.0. The n=15 benchmark's thresholds and coded-delivery rules are not the three n=5 committees' rules.

`S` means a source-defined semantic expectation. `P` means a proposed representation or selected mock arithmetic example, not authority to freeze an interface. The short Python oracle checks these expectations and fixed P bytes; it does not test production code. Genuine BLS, runtime, chain reader, and recovery validation are **INCONCLUSIVE / NOT RUN** in this stage.
