## 2. Independent invariant baseline

1. **Identity and actual state.** One immutable descriptor and original engine handle per cid. Recompute the existing O3 canonical cid from verified session/anchor id/ProgramConfig. Changed anchor id, config, verifier domain or session is a different context; same height is insufficient. State is not an identity field but must actually execute to this exact anchor. A matching state root, URI, boolean Ready or unverified material handle alone cannot establish Ready.
2. **Two state axes.** Phase is Assigned/Preparing/Ready/Running/Paused/Terminated. Selection is Candidate/Selected/Excluded. entered is monotonic. Selected is a public responsibility fact and can precede Ready/Enter; a legal candidate may Enter before Selected. Paused implies previously Entered. Terminated never returns to Ready/Running. TIME need not change selection to Excluded.
3. **One candidate scheduled per logical session.** Before public selection, prepare highest known valid anchors from the selected predecessor chain and schedule the highest Ready legal candidate. A higher Preparing candidate need not interrupt a current Ready/Running one. Public selection excludes mismatching candidates even if the chosen one still needs state. Only one generation of successor of a selected predecessor is preprepared; do not recursively run descendants of unselected candidates (GFR:261).
4. **Pause preserves the instance.** Switching A→B→A keeps A's original engine, view/locks/votes, signed bytes, first-receive records, entry time, absolute timer deadlines, pending requests and output obligations. Resume is scheduling of this state, not Create/Enter/reinitialization. An elapsed deadline is not replaced by resume_time+timeout. H1 must define the controlled due-work delivery mechanism; this oracle does not invent it.
5. **Terminal guard precedes effects.** Close durably records terminal state before invoking the original Program.Close; failure may retry Close idempotently but cannot allow signing. Check stop at actual sign出口 as well as Enter/Build/start of async work. All phases, including Preparing/Paused, are subject to stop/public closure. A later Ready completion cannot revive a closed context. Persisted signed history still matters in a no-OS-restart profile.
6. **Public order and local clock are different authorities.** Manager and Program share C_m. Local C_m≥stop prevents new signatures; only covered, locally replayed GFR events select/close public responsibility. Public time order is control→Expire→SessionEnd→Espresso at equal key. Neither receipt order, RPC time, wall time nor a Hub script chooses cid or moves a window.
7. **Proof, delivery, publication and admission are distinct.** FinalProof alone is not complete RegionalResult. Authenticate the descriptor/context/subject/quorum, physical ancestry and actual execution basis separately. A historical valid final proof is checked without re-running current observer-time admission. Publisher's verified task may outlive Program.Close; only actual public exclusion/cutoff or verified recording ends new-result retries. Keep its history even when STOPPED.
8. **Atomic lifecycle and replay identity.** Consume committed public records in order, preserving all events within a record, and dedupe by position+kind+full body. SessionClosed and SessionAssigned at the same pc are distinct. No external signing may observe a half-consumed close/assignment record. State preparation may remain pending after an accepted Selected fact: missing ReadyState is not license to keep the excluded instance running. Exact H2 batch commit/ack mechanics remain an H1/lead contract item.

## 5. GFR-LIFE-1 field expectations for later review

These are derived from the accepted O7 contract, not implementation. Reuse its public codecs; H2 must not create another public lifecycle encoding.

- ReplayPosition: checked key_us, kind/index match, exact position order; no raw-byte lexicographic ordering. Force/Resume share a class and compare actual L1 position. Genesis is pc=None, not a fabricated public event.
- SessionAssigned: entire checked Descriptor, including actual anchor id/metadata, exact Plan, fixed window and cid. Structural decode is not proof/source validation.
- SessionClosed: exact (beta,r) and original reason. BranchClosed: exact beta and reason. Scope includes Preparing/Paused, not just currently scheduled handles.
- Identity: `u16BE(1)||frame(encode_position(position))||u8(body_tag)||body`; body tags Assigned0/SessionClosed1/BranchClosed2/Resumed3, reason tags Time0/Complete1/Force2/Resume3/Expired4/Excluded5/Incompatible6. `frame` uses u32BE length. Existing lifecycle hash uses the exact `PoC/GfrLifecycle/v1` domain and existing u64BE hash-parts framing.
- Preserve full event/projection and ordered ReplayRecord membership. Deduplication identity is position+kind+complete body, not pc alone, cid alone or height alone. Consumed id cannot replace verification material.
- Whole-record application requires a named durable/ack policy. Pending ReadyState does not invalidate a previously committed public selection. Missing authenticated batch or required public transition inputs is different and cannot expose partial events.
- RESUME fields are codec reservations only; H2 current implementation must not fabricate ResumeCut or D. M2 Force accepts only future authenticated branch-close/assignment input through a separately accepted interface; no governance policy in H2.
