## Source-derived rules

Sources remain v10 02 §3.10/§4.5,03 §§3.2/3.5–3.6,04 §§3.4–3.5/PUB-1–3,09 §§3.2/3.4/4.2/4.7, frozen06 §§4.1–4.3 and frozen07 §§3/5/7/9. Dispatch decisions6–8 authorize dependency injection/extraction and preserve the public encoding and controlled-output boundary. Existing accepted component APIs were read as input dependencies, not used to compute expected results.

1. **Completeness is independent of selection.** For an explicit validated descriptor and target, return complete evidence iff the checked public cut contains at least one valid target proof and every canonical hash-linked physical body after that exact anchor through target. No NEXT, open-session, deadline, Expire or G-head predicate may be necessary to produce this evidence. Publisher can be RECORDED while G stays unchanged. GFR still applies all its separate selection, execution and timing guards.
2. **Exact public cut and provenance.** A body/proof beyond the explicit cut cannot complete an earlier query even if cached locally. Keep each exact public `(q,index)` and proof variant. Earliest completeness is `max(earliest valid proof q, each required body's earliest q)`; unknown/invalid proofs do not qualify. Additional late proof or optional old AnchorEvidence does not delay it. Missing required public body is incompleteness, not a source-prefix gap; a locally missing declared message prevents obtaining a complete prefix at that q.
3. **Known invalid versus unknown.** VerificationBasis WAIT or REJECT must occur before bool-checker invocation and must not be cached as an invalid proof verdict. A malformed/known-invalid proof does not pass and is diagnosed; if no valid proof exists the result is not complete. This need not reject an otherwise authentic source prefix. Once complete inputs exist, a known invalid parent/hash/window/context cannot be repaired by copying a computed value.
4. **One shared algorithm, pure result.** GFR and Publisher must use the same extracted completeness/ancestry/proof logic. A Publisher query must not mutate G, selection, accepted-records or a GFR cache tied to a different cut. In particular, a failed early query must not poison a later valid query. Refactoring must retain existing07 proof-location normalization and regression behavior.
5. **Native-only production boundary.** Publication bridge requires an immutable expected Native profile matching03 rule/verifier versions and exact supplied binding. Missing binding/basis yields WAIT, mismatch rejects, and there is no production fixture fallback/default verifier. Existing07 explicitly labeled fixture capability may remain for pure-component regression; making its helper blindly reject that accepted profile is unnecessary. Historical verification does not depend on live engine, selection, local Close/Pause/ClockUnsafe/current clock/lease. Fixture checkpoints/validated caches cannot be relabeled Native.
6. **Full Offer remains stricter than public completeness.** Check exact Plan/CID/config, target identity, actual full chain, anchor provenance and execution inputs before Verified. Use03 Plan/metadata/Merge mechanisms; read-only external anchor-provenance capability can return Ready/Wait/Reject until H1 supplies its implementation. A root alone is not execution evidence. Missing material returns Wait with retained partial result; bad material rejects. The same complete proof/chain check cannot stand in for Plan/anchor-source verification.
7. **Canonical emission and bounded private storage.** Public output is only existing GFR-PUBLIC-1 Body and FinalProof messages over exact03 canonical bytes; preserve proof bytes. Private durable result framing is allowed but is not a second public codec and must retain partial VERIFYING material. Validate bounds before allocation/output; malformed/trailing/unknown-version inputs reject.03 has no complete RegionalResult canonical encoder; define only a versioned private container that composes its existing field encodings.06 limits remain message65536, encoded attempt-list1048576, stored result4194304 and snapshot67108864. Smaller slice bounds must be named and checked, never silently truncated.
8. **Recorded is an actual public receipt.** Use the Publisher's source/reader-bound VerifiedPrefix, not source global state, submit ACK, header or G append. Receipt contains earliest valid target-proof publication position and actual checked complete-prefix bound; these differ from q_avail and acceptance pc. For proof atq1/body atq2, a prefix endingq2 gives publication_position=(1,index), complete_through_q=2, q_avail=2. Repeat observation preserves first receipt. Same ResultKey with different valid proof bytes does not replace the first durable payload or regress task state.
