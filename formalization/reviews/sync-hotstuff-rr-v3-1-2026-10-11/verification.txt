AUTHORIZED PROTOCOL
This manuscript follows the user's revised Protocols 1 and 2 and the agreed
terminal-QC backup forwarding rule. It is a new standalone file; v3 remains
unchanged. The article is in English, matching the existing manuscripts.

CORE EXECUTION
- Explicit parent selection by j and t, with separate anchor and genesis cases.
- Verifiable quit evidence is processed before outer-message validity/dedup.
- Every eligible previously unvoted current-generation DATA proposal uses one
  ordinary Vote handler, including older terms and proposals in attached history.
- One proposal-bound 2Delta timer starts on the local first DATA vote.
  No QC-start timer and no old-term vote skipping.
- Each correct replica sends a verified terminal QC plus dependencies once to
  the next leader. There is no extra vote phase or all-node QC broadcast.
- Local first terminal-QC admission defines the normal term start e_r(g,t).
  Duplicates do not reset entry times; normal rotation retains proposal timers.
- All p=1,...,K progress checks retain the (2p+4)Delta deadline.
- Complete quit proof freezes the entire generation and cancels unfinished
  timers; recovery always targets (g+1,0).
- Recovery entry waits for both quit+Delta and finalized next authority.
  STATUS fixes an entry lock, leader waits 2Delta, NEWVIEW selects an older QC,
  and ANCHOR re-voting starts no timer before the first fresh child.

RESOLVED FINDINGS
1. P1 originally used an ambiguous 'Otherwise' after processing any quit proof.
   It now returns only when evidence freezes the current generation, so an
   archival entry proof does not block new-generation DATA processing.
2. The initializer proof now establishes existence of its first fresh proposal:
   it is produced by e+5Delta, before any correct term-zero BLAME at e+6Delta;
   no later term is admitted before that first proposal exists.
3. The private-QC counterexample states 0<epsilon<Delta and schedules both
   the alternate honest vote and backup QC paths, closing a timing omission.
4. Complexity parameters and retrieval exclusions were made explicit.

SECURITY CONCLUSIONS AND COUNTEREXAMPLE SCOPE
No attack against the specified protocol under its full stated assumptions was
found in these reviews. The manuscript proves conditional safety and eventual
height/request liveness; its attack section labels the changed premise:
A. Skip old proposal processing while removing QC timers: some replicas never
   start a timer and may never commit.
B. Shorten normal first BLAME to 2Delta: a silent Byzantine successor can
   repeatedly cancel slower replicas' timers, without equivocation.
C. Remove permanent exclusion: for any finite K, sufficiently fast repeated
   equivocation can prevent every non-genesis commit.
D. Measure q+Delta from private Byzantine QC assembly: withheld QC information
   refutes that timing bound; first correct verified receipt is required.
E. Accept unauthenticated conflicts as proofs: fabricated messages force freezes.

LIMITS
These are mathematical reviews, not mechanized proofs or deployment testing.
The bounds require complete-message synchrony covering data dependencies and
validation, retained state, fixed voting membership and Byzantine identities,
immutable independently live L1 authority, permanent prospective proposer
exclusion, and the stated schedule/input fairness. No uniform L1 latency,
bounded number of failed generations, dynamic membership safety, or fixed
physical-time term schedule is established. The manuscript expressly permits
quadratic aggregate history-byte costs without a specified caching scheme.
